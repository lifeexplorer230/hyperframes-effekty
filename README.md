# Видеоэффекты HyperFrames - навык для ИИ-агента

Навык для Claude Code / Codex: из одного вашего клипа «говорящей головы» агент собирает вертикальный ролик
9:16 с монтажными эффектами - без Premiere, CapCut и таймлайна. Эффекты написаны кодом (HTML + CSS + GSAP),
видео рендерит [HyperFrames](https://github.com/heygen-com/hyperframes) локально на вашем компьютере.

33 эффекта: долли-зум «вертиго», карточки по орбите вокруг головы, слово за спиной, газетная вырезка, прицел по
лицу, точечный портрет, чек «0 ₽», штамп «отклонено», тир-лист, 3D-планета с вашим городом, раздвоенный экран
до/после и другие. Полная таблица - в [SKILL.md](SKILL.md).

## Пример результата

Вы записываете на телефон 27 секунд: «Двадцать четыре эффекта, один клип. Стекло. Вертиго. Орбита…» - и пишете
агенту «смонтируй ролик с 24 эффектами». Агент вырезает фон, находит лицо, распознаёт речь и ставит каждый эффект
ровно на слово, которым вы его называете: на «вертиго» фон за вами наезжает, на «орбита» вокруг головы летят
карточки, на «чек» из принтера выползает чек. Сверху - счётчик 01/24…24/24 и панель-чек-лист, в конце - карточка
«Напишите в комментариях слово ЭФФЕКТЫ», где это слово печатается в поле комментария.

Второй рецепт - «говорю команды, ИИ монтирует»: сверху смонтированное окно, снизу оригинал; вы говорите «раздели
экран и напиши пять навыков», «сделай ярче», «покажи 3D-планету» - и на экране это происходит в момент фразы.

## Установка

```bash
npx skills add lifeexplorer230/hyperframes-effekty
```

Или вручную: скопировать папку в `~/.claude/skills/hyperframes-effekty/` (Claude Code) или в папку навыков Codex.
Потом просто попросите агента: «смонтируй ролик с эффектами из моего клипа клип.mp4».

## Требования

- **Node.js 18+** - HyperFrames запускается через `npx hyperframes@0.9.88` (первый запуск скачает Chrome для рендера).
- **Python 3.10+** с `opencv-python`, `numpy`; для распознавания речи - `faster-whisper` (или `openai-whisper`).
- **ffmpeg** (с ffprobe).
- Клип 9:16, 25–30 с, лицо в кадре. Вырезка фона идёт на CPU: 7–14 минут на 30 секунд клипа; рендер ролика - 5–15 минут.

Платного ничего не нужно, всё работает локально. Модель поиска лица (YuNet, MIT) и карта стран (world-atlas, ISC /
Natural Earth) скачиваются скриптом `podgotovka.py` из официальных источников.

## Что внутри

```
SKILL.md                 инструкция для агента: шаги, рецепты, таблица эффектов, ловушки
scripts/biblioteka.py    библиотека эффектов (по функции на эффект)
scripts/podgotovka.py    лицо, чистый фон, точечный портрет, обложки из кадров, модель, карта
scripts/rech.py          речь → слова со временем (assets/slova.json)
scripts/rolik_24.py      рецепт «24 эффекта, 1 клип»
scripts/rolik_komandy.py рецепт «команды + до/после» по сценарию JSON
scripts/zvuk.py          звуки-акценты, фон с проседанием под голос, громкость −14 LUFS
scripts/list.sh          лист кадров для проверки
scripts/novyj_proekt.sh  новый проект из шаблона
shablon/                 hyperframes.json, package.json, шрифты с лицензиями
primery/                 пример сценария команд и карты звуков
```
